# The Lock-In — ENGR 102

Free static study site for personal use.

## Included
- 15 modules organized around the ENGR 102 lecture progression.
- Lesson objectives, concepts, worked examples, walkthroughs, practice questions, and solution notes.
- Local progress tracking with browser `localStorage`.
- Gemini prompt helper that copies lesson context and opens Gemini.
- Exam practice and reference Markdown files supplied in the course resource ZIP.

## Publish with GitHub Pages
1. Create a repository named `the-lock-in`.
2. Upload the contents of this folder to its root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, `main`, and `/ (root)`; save.
5. Wait for GitHub Pages to publish.

## Gemini
This site does not directly call the Gemini API. The helper prepares a contextual prompt for your Gemini app subscription. A Gemini app/student subscription does not automatically grant API billing or quotas. For direct API calls, a server-side backend is required; never commit API keys to a public repository. Check current Google API eligibility, limits, and terms before adding a backend.

## Progress
Progress is saved only in the browser/device used. The lessons themselves are static files in the repository and will persist across chats.

## Course sources
The lesson outline is based on the supplied ENGR 102 syllabus and lecture materials. The original exam practice/reference Markdown files are included. Large PowerPoint and PDF source files are not included in this website bundle.
